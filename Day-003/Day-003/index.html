01 · What AWS is

Servers, storage and networks, rented on demand

AWS is Amazon's cloud subsidiary. It gives you compute, storage, networking and databases through aws.amazon.com, and you scale them up or down as you need. Streaming apps, banks, AI products and online stores all run on it. When S3 goes down, even your class recordings stop playing.

Deployment types

Public cloud

Shared provider infrastructure, rented by many customers. AWS, Azure, GCP.

Private cloud

Cloud-style infrastructure dedicated to one organisation.

Hybrid cloud

A mix of the two, with workloads split between them.

Beyond the big three: the "X as a Service" family

FaaSFunction as a Service. Lambda: short, event-driven functions.
CaaSContainer as a Service. Docker and Kubernetes work.
DaaSDatabase as a Service. Managed databases.
STaaSStorage as a Service. Managed storage.
CaaSCompute as a Service. Raw compute on demand. Same acronym as containers, so say the full name in interviews.

Class tip: IaaS / PaaS / SaaS carries you to roughly 10 LPA roles. CaaS (containers) and FaaS knowledge is what higher packages ask for.

04 · Serverless & Lambda

The five-star hotel: bring only your code

No servers, OS or network to look after. Lambda wakes up when an event arrives, runs, and you pay per execution. Pick a use case from class and play it.

05 · Why DevOps won

Same six months, very different number of releases

Waterfall locks you into design → code → test → deploy with no going back. Agile ships every two-week sprint. DevOps automates build, test and deploy so shipping happens daily, with higher quality.

M1M2M3M4M5M6

Class figure for Agile was about 9 versions in six months. Strict two-week sprints give up to 13; the point is the same.

09 · Market & careers

Where the jobs are

AWS, Azure and GCP offer the same services under different names. Learn one deeply and you can work in any of them. Kishor moved from AWS to Oracle Cloud and found the concepts identical.

Cloud share, as taught (~2022 data)

AWS~40%
Azure~30%
GCP~30%

These are shares among the big three as quoted in class. Other providers (Oracle, Alibaba, IBM) also hold part of the overall market, so check a current report before quoting numbers in an interview. GCP is growing fastest (~26%), driven by Kubernetes and AI.
