# 🚀 Today's Learning: DevOps Principles & Practices

Today I started strengthening my understanding of **DevOps principles and practices**, focusing on how development, QA, and operations work together to deliver software faster, reliably, and with greater automation.

## 🔹 DevOps Fundamentals

- DevOps bridges Development, QA & Operations
- Automation helps reduce manual effort and human errors
- DevOps is not just about tools — it includes processes, collaboration, CI/CD, infrastructure, deployment and monitoring

## 🔹 SDLC & Development Workflow

- Understanding Product Owner → PM → Scrum Master → Team Lead → Developer flow
- Breaking requirements into Epics and Stories
- Using Git/GitHub for source-code management and collaboration
- Understanding commits, version history and accountability

## 🔹 DevOps Toolchain

| Area | Tools |
|---|---|
| Planning | Jira, Confluence |
| Code Management | Git, GitHub, GitLab |
| Build | Maven |
| Artifact Management | Nexus / JFrog Artifactory |
| Testing | Selenium, JMeter |
| CI/CD | Jenkins, GitLab CI, GitHub Actions |
| Containers | Docker, Kubernetes |
| Infrastructure as Code | Terraform |
| Automation | Ansible |
| Monitoring | Prometheus, Grafana, CloudWatch, Datadog |

## 🔹 Important Concepts

- **Docker** packages applications and dependencies into portable containers
- **Kubernetes** orchestrates containers at scale
- **Terraform** helps provision infrastructure using IaC
- **Ansible** automates configuration and operational tasks
- **Jenkins** automates build and CI/CD workflows
- **Prometheus + Grafana** can be used for metrics and visualization

## 🔹 Release vs Deployment

One important distinction I learned:

- **Release** = moving/creating a new version of an artifact across environments
- **Deployment** = actually placing and running that application in the target environment

## 💡 Key Takeaway

The biggest takeaway for me today:

> **DevOps is more about understanding the complete software delivery lifecycle and automating it effectively than simply learning a collection of tools.**
