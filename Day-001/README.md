# Day 001 - DevOps Learning Log

## Topics Covered
- DevOps fundamentals — how Development, QA & Operations work together
- SDLC workflow: Product Owner → PM → Scrum Master → Team Lead → Developer
- Breaking requirements into Epics and Stories
- Git & GitHub for source-code management and collaboration
- DevOps toolchain overview across planning, build, CI/CD, IaC, and monitoring
- Core tools: Docker, Kubernetes, Terraform, Ansible, Jenkins, Prometheus & Grafana
- Release vs Deployment — the distinction between the two

## Key Takeaways
- DevOps is more about understanding and automating the full software delivery lifecycle than about learning a fixed set of tools
- Automation reduces manual effort and cuts down on human error across the pipeline
- **Release** = moving/creating a new version of an artifact across environments
- **Deployment** = actually placing and running that application in the target environment
